문항 품질 기준

근거와 정답
- 답을 결정하는 대상·성립 조건·범위·단위·정의역은 지문에 명시하고 해설에서 새 가정을 추가하지 않는다. 근거의 발화 주체·시점·관점·적용 대상을 지문·보기·정답·해설에도 유지한다. ‘자료의 구분’만으로 발언 주체나 관점을 대신하지 않는다. 특정 관점을 전체의 보편적 정의로 확대하지 않는다. 서로 다른 기능·조건·상태를 같은 원인이나 결과로 바꾸어 쓰지 않는다.
- 한 문항은 명확한 학습 과제를 묻는다. 공유 상태에서 분기하는 판단이나 여러 근거의 통합도 허용한다. 사례의 정보가 답을 결정하게 하며 방법 선택과 판단의 연결로 난도를 조절한다. 문장 길이·낯선 용어·계산량으로 난도를 높이지 않는다. 표현이나 설명 분량이 다르다는 이유만으로 실제 개념·기법이 서로 배타적이라고 전제하지 않는다. 근거가 지지하는 공통점·포함 관계·허용 대안도 인정한다.
- mcq는 goal의 같은 질문 기준에 대한 네 대안이다. 공통 조건은 유지하고 구별할 관계·범위·예외의 적용이 답을 결정하게 한다. 각 오답의 explanation에는 어떤 잘못된 적용으로 선택할 수 있는지와 학생에게 주어진 조건에서 왜 틀리는지를 연결한다. 실제 학생 통계로 확인된 오개념이라고 주장하지 않는다. 유사 개념의 경계가 목표인 비교는 허용하되, 엉뚱한 정의 치환이나 여러 명백한 오류로 쉽게 버릴 보기만 채우지 않는다.
- 정답 표시를 정하기 전에 네 보기 각각을 실제 지문의 모든 조건 아래에서 읽는다. 일반적으로 잘못된 설명도 이 조건에서 참으로 읽히면 오답으로 쓰지 않는다. 모든 보기에 같은 질문 기준을 적용하고, 조건부로 참인 대안을 덜 권장되거나 실행되지 않았거나 원문에 없다는 이유로 거짓 처리하지 않는다. 배제 근거가 되는 조건을 지문 밖에서 보태지 않는다. ‘가장 적절’은 복수의 타당한 답을 해결하지 않는다. 선지의 길이·문법·구체성을 맞추되 애매하게 만들지 않는다.

평가 형식과 문장
- ox는 한 학습 판단을 대상으로 한다. 여러 조건이 같은 관계 판단에 필요한 경우는 허용하되 독립 사실들을 모두 참이라고 확인하는 목록으로 만들지 않는다. 문장 수·접속사 수로 단일성을 판단하지 않으며 O/X 비율을 맞추려고 없는 예외를 만들지 않는다. X의 해설에는 올바른 내용을 적는다. passage에는 필요한 제시문·조건만, stem에는 학생이 참거짓을 판단할 진술만 쓴다. 판단할 결론이나 정답의 이유를 passage에서 먼저 알려주지 않는다. O/X 선택 안내는 앱이 별도로 표시하므로 중복 작성하지 않는다.
- word는 수치·조건·수정 내용·짧은 결론을 요구할 수 있다. essay는 답변 범위를 정하고 타당한 다른 표현을 허용한다.
- 주어·목적어·비교 기준을 명시하고 전공상 다른 대상·속성·상태를 혼용하지 않는다. 이해완성·기출 N제에서는 명칭 매칭만으로 요구한 판단을 대신하지 않는다.
- 모든 유형에서 필요한 제시문·코드·상황·수치는 passage에, 명확한 질문·요구는 stem에 나눈다. 별도 제시문이 필요 없으면 passage는 빈 문자열이다. 문항 안에서 ‘자료는/자료의 관점에서’라고만 쓰지 않는다. 문항의 passage를 가리키면 ‘아래 제시문에서/제시문에 따르면’처럼 대상을 명시하고, 원본 PDF를 가리키면 출처의 실제 저자·관점·개념을 밝혀 자족적으로 묻는다. 학생이 보지 않는 PDF를 뜻하는 ‘자료’와 문항에 보이는 제시문을 섞지 않는다. 객관식의 선택 가능한 선지는 options 또는 distractors에만 쓰고 stem·passage에 번호와 함께 중복 나열하지 않는다. 자료 분석용 ㄱ·ㄴ 등의 항목은 실제 선택 선지와 구별한다. 같은 요구·배경의 재설명과 독립 요구의 나열을 덜고 필수 전제·수치·코드를 줄이지 않는다.
- 명확한 긍정형 질문을 기본으로 한다. 부정형·절대 표현은 평가 대상에 필요한 경우만 사용한다. 한국어는 자연스럽게 쓰고 기호·첨자·코드 식별자는 보존한다. 설명은 ‘~이다/~한다’, 요구는 ‘구하시오/고르시오/설명하시오’이다.
- 해설은 개념·사례의 역할·성립 조건을 연결해 결론의 근거를 충분히 보여준다. 오답 해설은 해당 보기의 실제 주어·대상·관계를 짚고, 틀린 주장과 올바른 관계를 같은 대상에 대해 설명한다. 보기 기호에 의존하거나 주어를 뒤집지 않는다. 좋은 해설을 줄여 난도를 높이지 않는다. 다른 문항의 답을 힌트로 주지 않는다.
